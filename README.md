# homebrew-tap

Personal [Homebrew](https://brew.sh) tap.

## mdcat

A terminal Markdown viewer for [kitty](https://github.com/hoonkim/mdcat).

```bash
brew install hoonkim/tap/mdcat
```

## timecat

A large 7-segment digital clock for modern terminals.

```bash
brew install hoonkim/tap/timecat
```

## mail-strainer

A Gmail spam classifier using [gws](https://github.com/googleworkspace/cli) and OpenRouter, with a local SQLite web UI.

```bash
brew install hoonkim/tap/mail-strainer
```
